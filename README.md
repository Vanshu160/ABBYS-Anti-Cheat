**ABBYS Anti-Cheat**

Focused on Minecraft Java Mobile launcher security, client forensics, and cheat detection.

Unlike traditional server-side anti-cheats, ABBYS investigates accessible Minecraft and launcher files, logs, configurations, mods, and digital traces to identify suspicious client modifications through evidence-based analysis.

### 🛡️ Core Features

- Cheat Client Signature Detection
- Minecraft Log & Crash Report Analysis
- JAR, Class & Mod Inspection
- Suspicious File Analysis
- Launcher Forensics
- Zalith, Mojo & PojavLauncher Support
- External Storage Scanning
- Evidence Correlation & Confidence Scoring
- Detailed Scan Reports
- PIN-Protected Access

### 📱 Platform

- Android application
- Minecraft Java Edition forensic analysis
- Android 11+ compatibility, subject to storage permissions

## Discord copy of every report (optional)
Set the Render environment variable `DISCORD_WEBHOOK_URL` to a Discord webhook URL (Channel settings > Integrations > Webhooks). Every uploaded report is then also posted there: a coloured embed with the verdict, detections, finding counts, and the full report attached as a text file. The URL is only accepted if it is an exact `discord.com` webhook, `@mentions` never fire, and a Discord failure never affects the upload. Leave it unset to turn this off. Discord allows about 30 posts a minute per webhook.
